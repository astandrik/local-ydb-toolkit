The local MCP server groups tools by operational responsibility. Ask your MCP
client to list tools for the exact version currently installed.

| Group | Examples | Boundary |
| --- | --- | --- |
| Checks | inventory, status, healthcheck, logs, tenant, nodes, auth, storage | Read-only |
| Schema | generate and validate table DDL, apply schema | Generation and validation are read-only; apply is plan-first |
| SQL | query, explain, execute managed YQL | Query is SnapshotRO; execute requires confirmation |
| Lifecycle | bootstrap, restart, create tenant, image pull, destroy | Plan-first mutation |
| Auth | prepare config, write token file, apply hardening, rotate password | Plan-first mutation |
| Storage | inspect placement, add or reduce groups, clean storage | Inspection is read-only; changes are plan-first |
| Backup and restore | list dumps, dump, restore | Listing is read-only; dump and restore are plan-first |
| Dynamic nodes | add and remove extra nodes | Plan-first mutation with per-node verification |

## Recommended entry points

- New target: `local_ydb_check_prerequisites`.
- Unknown failure: `local_ydb_status_report`, then `local_ydb_healthcheck`.
- Generic local database: `local_ydb_bootstrap_root_database`.
- CMS tenant, GraphShard, dump/restore, or dynamic nodes: `local_ydb_bootstrap`.
- New table DDL: `local_ydb_generate_schema`, review, validate, then `local_ydb_apply_schema`.
- General work against an arbitrary existing YDB endpoint: use the official
  [`ydb-platform/ydb-mcp`](https://github.com/ydb-platform/ydb-mcp).

The generated catalog in the repository
[README](https://github.com/astandrik/local-ydb-toolkit#tools) is the public
reference for the current release.
