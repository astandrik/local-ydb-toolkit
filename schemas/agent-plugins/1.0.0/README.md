# Agent Plugins schemas 1.0.0

These files are immutable local snapshots of the canonical Agent Plugins 1.0.0 schemas:

- `https://agent-plugins.org/schemas/1.0.0/plugin.schema.json`
- `https://agent-plugins.org/schemas/1.0.0/mcp.schema.json`

They were retrieved on 2026-08-12. `SHA256SUMS` records the canonical response hashes. CI validates local manifests without fetching schemas at plugin load or test time. Update this directory only when deliberately targeting a new Agent Plugins specification version.
